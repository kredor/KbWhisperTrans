# KbWhisperTrans
Gör det på 350 symboler        8:43       Windows-program som transkriberar ljudfiler lokalt med KB-Whisper för svenska och Distil-Whisper för engelska. Startas via högerklick eller programfönster. Visar förlopp, hastighet och återstående tid. Sparar texten som en Markdown-fil med samma namn i ljudfilens mapp. Inga ljudfiler laddas upp.
